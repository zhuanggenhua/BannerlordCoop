## Implementation

`CampaignCycleDiagnostics.cs` targets only MobilePartyHourlyTick, PeriodicHourlyTick, PeriodicDailyTick, PeriodicQuarterDailyTick and TickPartialHourlyAi. Its transpiler replaces each existing PeriodicTickSome call/callvirt with a nongeneric static wrapper for MobileParty, Settlement, Town, Hero or Clan. The same receiver and double elapsed remain on the evaluation stack; labels and exception blocks stay attached. Unexpected signatures/types or changed callsite counts fail explicitly. There is no Harmony patch on a generic method, pointer deduplication or reflection invocation of the original.

Each typed wrapper calls the original native PeriodicTickSome exactly once. On a native exception it records that same exception and uses bare throw to preserve identity/stack. The completion helper is deliberately named CompleteBatch rather than Harmony's convention name Finalizer, so the callsite patch class installs only a transpiler. BeginNativeBatch resolves the actual receiver against this Campaign's20 fields; foreign instances run without being misattributed.

Each call has a thread-local parent boundary. Callbacks append to only the current boundary; finalization restores its parent even on a native exception. Expected sequences use the actual method's double elapsed argument, not an outer group's independently recomputed delta. List identity/order, Index and exact debt remain strict. Full failure JSON records all predicate results, before/after IDs, full expected/completed arrays, original and expected/final indices, debt/elapsed IEEE bits, UTC, engine frame, thread IDs/depth and lease identity. The first failure remains immutable in the existing aggregate.

Capture is bounded at32768 identities and32768 callbacks per native batch. Exceeding a bound is an explicit diagnostic mismatch with `complete=false`; it never becomes PASS and is never silently represented as complete evidence. Prediction also rejects nonfinite debt and cannot loop indefinitely on excessive catchup. Original native execution is not changed by those diagnostic bounds.
