## Composition and boundaries

The existing `CampaignSimulationAuthorityPolicy` decides active simulation, already-executed local result publication and confirmed network result sending. Constructor/active mutation eligibility and result publication are distinct. `CanSendWorldResult` requires the actual context and a confirmed writer lease; missing context or an unconfirmed context cannot send classified raw payloads. The legacy local initialization/registration behavior remains available, and startup objects reach peers through the original save/registration snapshot.

`ClientModule` additionally composes the original `ServerSettlementComponentHandler` and `SendCoalescer`; `ServerModule` additionally composes the original `ClientSettlementComponentHandler`. Their own namespace scans do not include the opposite handler, so each type is composed once. Owner/Gold/IsOwnerUnassigned retain their original conversion bodies and payload fields. Gold retains the original per-component latest-wins coalescer. `CoopClient.Update` uses the same game-thread flush approach as `CoopServer.Update`; the existing `CampaignAuthorityFreezeClientHandler` flushes the same lifetime-scope coalescer before `TryFreezeLocalAuthority` inside the current-lease boundary. No complete module is stacked.

All three setters first run the permission adapter and then publish the actual completed native result from their postfix. Explicit Bootstrap/CheckpointInstall may initialize an unregistered native object without publishing. A registered object, an unspecified observer callback or an arbitrary WorldWrite does not gain that initialization permission. Replay uses the existing AllowedThread native apply path, now under explicit Replay provenance. Registry resolution runs inside the game-thread action, and missing references fault the actual apply receipt.

## Join and catch-up ordering

`AuthorityLeaseDistributionHandler.Handle_CampaignReady` calls `InitializeLocalAuthorityController`, which confirms the lease. `Handle_PlayerConnected` repeats confirmation and uses `INetwork.SendImmediate(NetworkAuthorityLeaseSnapshot)` because `ConnectionMessageQueue` initially drops pre-save world broadcasts. The existing immediate metadata path survives that dropping phase before the ordinary save/incremental catch-up stream. A new join while B is an active remote writer is explicitly refused when no complete checkpoint is available. This change does not claim pre-lease bare-scoped network compatibility and does not relax `MessagePacketHandler`'s unwrapped-message rejection. Existing `AuthorityLeaseDistributionHandlerTests` exercise this production metadata path and unavailable-checkpoint refusal.
